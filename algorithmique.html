Recherche du maximum

Idée : Parcourir le tableau en gardant la plus grande valeur vue.

Pas à pas : [4, 9, 2] : max=4 → 9 > 4 donc max=9 → 2 < 9 → résultat 9

fonction maximum(T)
    max ← T[0]
    pour i de 1 à longueur(T)-1
        si T[i] > max alors max ← T[i]
    retourner max
Ta traduction en Python ou C + ton organigramme

Tri à bulles

Idée : Comparer les voisins et les échanger s'ils sont dans le mauvais ordre, jusqu'à ce que tout soit trié.

Pas à pas : [5, 2, 4] → [2, 5, 4] → [2, 4, 5]

pour i de 0 à n-2
    pour j de 0 à n-i-2
        si T[j] > T[j+1] alors échanger T[j], T[j+1]
Ta traduction en Python ou C + ton organigramme

Recherche dichotomique

Idée : Dans un tableau trié, couper l'intervalle en deux à chaque étape.

Pas à pas : [1,3,5,7,9], cible 7 : milieu 5 → droite ; milieu 7 → trouvé

debut ← 0 ; fin ← n-1
tant que debut ≤ fin
    m ← (debut + fin) div 2
    si T[m] = cible alors retourner m
    sinon si T[m] < cible alors debut ← m+1
    sinon fin ← m-1
retourner -1
Ta traduction en Python ou C + ton organigramme
