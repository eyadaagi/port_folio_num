Prompt engineering

Poser la bonne question pour obtenir une bonne réponse.

Les éléments d'un bon prompt

🎭 Rôle

Qui doit répondre ? « Tu es un professeur de… »

🌍 Contexte

Ta situation, ton niveau, ton objectif.

🎯 Tâche

Ce que tu veux, avec un verbe d'action clair.

📐 Format

Tableau, liste, longueur, langue.

🚧 Contraintes

Ce qu'il faut éviter ou respecter.

💡 Exemples

Un modèle de réponse attendue.

Les techniques

  1. Raisonner étape par étape : demander de détailler la démarche.
  2. Donner des exemples pour cadrer le style attendu.
  3. Itérer et affiner : corriger le prompt à partir du résultat.
  4. Demander une vérification : relecture, sources, points d'incertitude.

Bibliothèque de prompts

Expliquer un cours

Tu es un professeur patient. Explique-moi [notion] comme si j'avais 15 ans, avec une analogie du quotidien, puis 3 questions pour vérifier ma compréhension.

Corriger mon code

Voici mon code [code] et l'erreur [message]. Ne me donne pas la solution : explique la cause et pose-moi une question pour que je trouve la correction.

Fiche de révision

À partir de ce cours [texte], crée une fiche de révision : définitions clés, 5 points à retenir, 1 exemple. Format : titres + puces.

Vérifier mes sources

Voici ma réponse : [texte]. Liste les affirmations à vérifier et propose où les contrôler (sources officielles).

Quiz d'entraînement

Pose-moi 5 questions de difficulté croissante sur [sujet], une à la fois. Attends ma réponse avant de corriger.
