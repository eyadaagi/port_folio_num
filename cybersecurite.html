Digital Skills · Chapitre 1

Se protéger sur Internet

Comprendre les menaces pour mieux les éviter.

Les logiciels malveillants

🦠

Virus

Programme qui s'attache à un fichier et se propage quand on l'exécute. Il peut corrompre ou supprimer des données.

🪱

Ver

Se copie tout seul d'un ordinateur à l'autre via le réseau, sans action de l'utilisateur.

🐴

Cheval de Troie

Se cache dans un logiciel d'apparence légitime pour ouvrir une porte dérobée au pirate.

🔒

Ransomware

Chiffre tes fichiers et exige une rançon pour les rendre. Parade : sauvegardes hors ligne.

👁️

Spyware

Espionne discrètement tes activités : frappes clavier, mots de passe, navigation.

Les risques du quotidien

  • Hameçonnage (phishing) : faux mails ou SMS qui imitent une banque, un livreur, l'administration.
  • Arnaques : fausses boutiques, faux gains, faux supports techniques.
  • Vol de comptes : mots de passe réutilisés ou devinés.
  • Fuite de données : un site piraté expose tes informations personnelles.
